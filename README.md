# ai-news-app
# 🤖 AI News Analyzer

An AI-powered News Analysis web application that extracts, summarizes, and analyzes news articles using NLP techniques. It provides summaries, highlights, keywords, sentiment analysis, and Hindi explanation in a simple web interface.

---

## 🚀 Features

- Analyze any news article using URL
- Automatic news summarization
-  Keyword extraction
-  Important highlights generation
-  Sentiment analysis (Positive / Negative / Neutral)
-  Hindi explanation of news
-  Voice output using speech synthesis
-  Simple and interactive UI
-  Visual representation of news
-  support translation into many languges
